# ha-for-korea

한국 서비스를 Home Assistant에 연결하는 커스텀 통합입니다.

- 한전ON: 전기요금과 월별 사용량(개인 계정, 아파트·오피스텔·주택용 계약).
- 서울 지하철: 실시간 도착정보, 수도권 노선도·경로 검색, iPhone 이동 안내.
- 음식물쓰레기 RFID: 이번 달·지난달 배출량과 배출 횟수.
- 디데이: 목표 날짜까지 남은 일수, D-Day·D+ 표시, 매년 반복.
- 마트·SSM 휴일: 지점별 공식 휴무일, 다음 휴무일, 남은 일수.
- 버전: `v1.4.1`.
- Home Assistant 2026.8.3 이상.

## 설치

HACS 사용자 지정 저장소에 `https://github.com/dhlife09/ha-for-korea`를
`Integration`으로 추가하고 설치합니다. HA 재시작 후 **HA for Korea**를 추가하고
서비스를 선택하세요. 기존 한전ON 설정과 엔터티는 유지됩니다.

## 한전ON 설정

한전 계정으로 로그인하고 조회할 계약을 선택합니다. 기본 조회 주기는 12시간,
사용량 이력은 12개월입니다. 비밀번호 저장은 기본적으로 꺼져 있으며 세션 만료 시
다시 로그인해야 합니다. 토큰·쿠키는 저장되므로 HA 설정과 백업을 보호하세요.
계약에 따라 예상요금·현재 사용량이 제공되지 않을 수 있습니다.

## 서울 지하철 설정

**지하철 인증키는 [서울 열린데이터광장](https://data.seoul.go.kr/)에서 발급받습니다.**
발급받은 지하철 인증키, 역 이름, 노선을 입력합니다. 역별로 통합을 추가할 수 있으며 방향별 다음·다다음 열차 센서가 생성됩니다.
공식 전체 역명표로 짧은 이름과 괄호 안 부역명을 정식 API 이름으로 변환합니다.
역명표는 서울시 HTTPS 서버에서 키 없이 내려받아 HA에 캐시합니다. 이름이 모호하면
전체 역명을 입력하세요. API가 반환한 도착 안내와 목적지·열차번호·예상 도착시각을 표시합니다.
5분을 넘긴 응답과 출발한 열차는 표시하지 않으며 미제공 시간을 0초로 추정하지 않습니다.

기본 갱신은 120초입니다. 같은 키의 호출은 서울 기준 하루 950회로 제한하며
실패한 요청도 포함합니다. 여러 역이나 다른 앱에서 키를 함께 쓰면 한도에 유의하세요.
조회 실패 시 센서는 사용 불가, 현재 열차 정보가 없으면 ‘도착정보 없음’으로 표시합니다.

서울시 API의 HTTP 주소는 키와 역명을 평문으로 전송하므로 설정에서 명시적으로
동의해야 합니다. 키는 HA 설정과 백업에 암호화 없이 저장됩니다. 개발자 서버를
거치지 않고 서울시 API에 직접 요청하며 진단에는 키·역명·노선을 포함하지 않습니다.

[지하철 전용 화면 설치 방법](docs/SUBWAY_DASHBOARD.md): 노선도에서 출발·도착·경유역을
선택하고 iPhone 실시간 현황을 시작·종료할 수 있습니다. 탑승과 환승은 직접 확인하며,
예상 시간은 대기·지연을 포함하지 않습니다. 안내는 최대 2시간, API 조회는 120초 간격입니다.
실시간 방향을 확인하지 못한 노선은 도착정보를 표시하지 않습니다.

## 음식물쓰레기 RFID 설정

[환경공단 간편조회](https://www.citywaste.or.kr/portal/status/selectSimpleEmissionQuantity.do)에
사용하는 태그 인쇄번호와 동·호수를 입력합니다. 계정 비밀번호는 필요하지 않습니다.
배출 기록이 없어도 등록할 수 있습니다. 입력 정보가 틀려도 빈 응답이 올 수 있으니
태그 번호와 동·호수를 확인하세요.
월별 모든 페이지를 합산해 배출량(kg)과 배출 횟수 센서 4개를 생성합니다.
기본 조회 주기는 24시간이며 옵션에서 12·24·48시간을 선택할 수 있습니다.
정상 응답에 배출 기록이 없으면 0kg·0회(`lookup_status: no_records`),
통신·응답 오류 시 `unavailable`로 표시합니다.
직접 갱신하려면 **개발자 도구 → 작업 → `homeassistant.update_entity`**에서
RFID 센서 하나를 지정합니다. 같은 통합의 센서 4개가 함께 갱신됩니다.
실시간 배출량이나 수수료를 계산하지 않습니다.

태그 번호와 동·호수는 HA 설정·백업에 암호화 없이 저장되며 환경공단 HTTPS 서버로
직접 전송합니다. 개발자 서버는 사용하지 않으며 진단과 센서 속성에는 식별정보가 없습니다.


## 디데이 설정

이름과 목표 날짜를 입력합니다. 디데이 표시·남은 일수·목표 날짜 센서가 생성되며
HA에 설정된 시간대의 자정에 갱신합니다. 매년 반복을 선택할 수 있으며,
2월 29일은 평년에 2월 28일로 계산합니다. 설정은 HA 내부에만 저장됩니다.

## 마트·SSM 휴일 설정

브랜드와 지점명으로 검색한 뒤 정확한 지점을 선택합니다. 이마트·트레이더스,
에브리데이, 노브랜드, 롯데마트, 롯데슈퍼의 공식 공개 자료를 사용합니다.
계정이나 API 키가 필요하지 않습니다. 기본 조회는 12시간마다 진행하며,
휴무 안내·다음 휴무일·남은 일수 센서를 생성합니다. 현재 영업시간을 판정하지 않습니다.

이마트 계열은 이번 달과 다음 달, 롯데는 공식 API에서 제공한 날짜를 조회합니다.
특히 롯데슈퍼 일부 점포는 휴무일 자료가 비어 있어 ‘휴무일 미게시’로 표시됩니다.
둘째·넷째 일요일로 임의 추정하지 않습니다. 직접 확인한 날짜를 설정/옵션에서
입력하면 자동 일정을 대체하며, 입력을 비우면 공식 조회로 돌아갑니다.

[대시보드 카드 추가 방법](docs/DASHBOARD.md)을 참고하세요.
