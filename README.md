# ha-for-korea

한국 서비스를 Home Assistant에 연결하는 커스텀 통합 저장소입니다.

현재 지원: 한전ON 전기요금·월별 사용량(개인 계정, 아파트·오피스텔·주택용 계약).
- 버전: `v1.0.0`.
- Home Assistant 2026.8.3 이상.

## 설치

1. HACS → 커스텀 저장소에 `https://github.com/dhlife09/ha-for-korea`를 추가합니다. 종류는 Integration입니다.
2. 설치 후 Home Assistant를 재시작합니다.
3. 통합 추가에서 `HA for Korea · 한전ON`을 선택하고 계정과 조회할 계약을 설정합니다.

기존 `kepco_on` 설치와 같은 도메인을 사용하므로 기존 HACS 설치를 교체하세요.

## 설정

- 조회 간격: 기본 12시간, 옵션에서 1·3·6·12·24시간 선택.
- 비밀번호 보관: 기본 꺼짐. 꺼도 세션 토큰과 쿠키는 저장되며, 만료되면 다시 로그인해야 합니다.
- 사용량 이력: 기본 12개월, 옵션에서 1~24개월 선택.
- 오피스텔 예측 사용량은 단위가 확인되지 않아 표시되지 않을 수 있습니다.

설정·세션·백업에는 고객 식별정보가 포함됩니다. 외부에 공유하지 마세요.

추가 서비스는 이후 개별 통합으로 확장할 예정입니다. 현재 한전ON 외 기능은 없습니다.
