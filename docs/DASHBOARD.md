# 디데이·마트 휴일 카드

통합을 추가하면 각각 센서 3개가 생성됩니다. HA 대시보드의 **편집 → 카드 추가**에서
디데이는 **타일**, 마트는 **엔터티** 카드로 원하는 센서를 선택하면 됩니다.
다음 휴무일과 남은 일수도 엔터티 카드에 함께 선택할 수 있습니다.

미리 만든 예제를 쓰려면 **카드 추가 → 수동**에 아래 YAML 파일의 내용을 붙여 넣습니다.
별도 프런트엔드 리소스나 카드 플러그인을 설치할 필요가 없습니다.

- [디데이 타일](../examples/dday-card.yaml): `sensor.my_dday_display`를 생성된 **디데이** 센서 ID로 바꿉니다.
- [마트 휴무일 목록](../examples/mart-holiday-card.yaml): `sensor.my_mart_status`를 생성된 **휴무 안내** 센서 ID로 바꿉니다.

센서 ID는 **설정 → 기기 및 서비스 → HA for Korea → 해당 기기 → 센서 설정**에서 확인합니다.
여러 일정·지점을 추가했다면 각 센서 ID로 카드를 추가하세요.

마트의 ‘오늘 정기휴무일 아님’은 현재 영업 중이라는 뜻이 아닙니다.
‘휴무일 미게시’는 공식 날짜를 받지 못했다는 뜻이며, 다음 휴무일을 임의 계산하지 않습니다.
직접 입력한 날짜는 자동 일정을 대체하며 카드에도 직접 입력한 일정임을 표시합니다.
