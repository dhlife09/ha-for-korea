# 보안

현재 한전ON 모듈은 한전ON HTTPS 서버로 계정 및 계약 정보를 전송합니다.

- 비밀번호 저장은 기본적으로 꺼져 있습니다.
- 저장을 꺼도 세션 토큰과 인증 쿠키는 HA 저장소에 남습니다.
- 설정과 세션 파일은 이 통합에서 별도로 암호화하지 않습니다.
- 고객번호·고객명·토큰이 담긴 설정, 백업, HAR 파일은 공유하지 마세요.
- 문제를 제보할 때는 버전, 오류 단계, 통합에서 제공하는 진단 요약을 사용하세요.
- 지하철 모듈은 서울시 HTTP API에 키와 조회할 역명을 직접 전송합니다. 평문 전송 동의가 필요합니다.
- 지하철 API 키는 HA 설정과 백업에 암호화 없이 저장됩니다. 개발자 서버로 보내지 않습니다.
- 지하철 오류 메시지와 진단에는 키·역명·노선·응답 본문을 넣지 않습니다.
