# 지하철 전용 대시보드

HA for Korea의 지하철 카드는 수도권 노선도에서 출발·도착·경유역을 선택하고,
선택한 경로의 열차 도착 안내를 iPhone으로 보냅니다.

1. HA for Korea를 업데이트한 뒤 Home Assistant를 재시작합니다.
2. **설정 → 대시보드 → 리소스**에서 `/kepco_on/ha-korea-subway-card.js`를
   **JavaScript 모듈**로 등록합니다. 리소스 메뉴가 보이지 않으면 사용자 프로필에서
   고급 모드를 켭니다.
3. 대시보드 편집에서 **지하철** 뷰를 만들고 경로를 `subway`로 지정합니다.
4. **카드 추가 → 수동**에 [지하철 카드 예제](../examples/subway-card.yaml)를 넣습니다.
5. `notify_service`를 자신의 iPhone 알림 서비스로, `url`을 실제 지하철 뷰 주소로
   바꿉니다. 알림 서비스는 **개발자 도구 → 작업**에서 `notify.mobile_app_`로
   검색할 수 있습니다. 카드에 비밀번호나 API 키를 넣지 않습니다.

예제의 `/lovelace/subway`는 기본 대시보드의 지하철 뷰 주소입니다.
별도 대시보드라면 해당 주소로 바꿉니다.

## 사용

- 역을 검색하거나 노선도의 역을 누른 뒤 **출발**, **도착**, **경유**를 선택합니다.
  노선도는 드래그로 이동하고 손가락 두 개 또는 `+`·`−`로 확대·축소합니다.
- **예상 시간 우선** 또는 **최소 환승**을 선택하고 **경로 검색**을 누릅니다.
  경유역은 선택한 순서대로 지나며 최대 5개까지 지정할 수 있습니다.
- **iPhone 이동 안내 시작**을 누르면 현재 구간의 도착 안내를 표시합니다.
- 실제로 열차에 타면 **탑승 완료**, 환승역에 도착하면 **환승역 도착**을 누릅니다.
  마지막 구간에서는 **목적지 도착**을 누릅니다.
- **안내 종료**로 이동 안내를 중지할 수 있습니다. iPhone 알림을 눌러 이 뷰로
  돌아올 수 있습니다.

위치는 자동으로 추적하지 않습니다. 탑승 뒤 남은 시간은 경로 소요시간을 기준으로
추정하며, 열차 지연·정차·대기시간 때문에 실제와 다를 수 있습니다.
카드의 상태는 30초마다 확인되지만 공공 API의 실제 조회 간격과 제한은 통합에서 관리합니다.

실시간 도착정보는 HA for Korea의 서울 지하철 통합 설정과 서울 API 키가 필요합니다.
키는 [서울 열린데이터광장](https://data.seoul.go.kr/)에서 발급받습니다.
iPhone에서는 Home Assistant 앱의 Live Activities 기능을 켜야 합니다.
잠금 화면과 다이내믹 아일랜드 표시는 Home Assistant iOS 앱이 제공합니다.

안내 시작은 HA 관리자 계정에서 사용할 수 있습니다. 안내는 최대 2시간 동안 유지되며,
열차를 기다리는 구간은 120초마다 조회합니다. 같은 인증키의 하루 950회 제한을 기존
도착정보 센서와 공유합니다. 실시간 방향을 검증한 1~9호선에서만 도착 안내를 제공합니다.
탑승 뒤 시간은 추정값입니다. 안내는 HA 재시작 시 복구되지 않습니다.

실시간 현황을 누르면 지정한 지하철 화면으로 이동합니다. 함께 보내는 일반 알림에는
**안내 중지** 버튼이 있습니다. 실시간 현황 자체에는 사용자 버튼을 추가할 수 없습니다.
알림창에서 표시를 닫는 것만으로 서버 조회가 중지되지 않으므로 안내 중지를 사용하세요.
