# 지하철 경로 데이터

노선도와 경로 검색은 함께 배포하는 `frontend/subway-network.json`을 사용합니다.
수도권 도시철도 24개 노선의 역·노선·환승 연결 정보를 담았습니다.

## 출처

- 역명, 노선 연결, 환승 식별자, 도식 좌표: [서울교통공사 사이버스테이션](http://www.seoulmetro.co.kr/kr/cyberStation.do)의 공개 `getLineData.do` 데이터. 2026-10-05에 확인했습니다.
- 일부 역간 표준 운행시간: 서울교통공사 제공 [서울교통공사_역간거리](https://data.seoul.go.kr/dataList/OA-12034/F/1/datasetView.do)의 `서울교통공사 역간거리 및 소요시간_240810.csv`. 공공누리 1유형(출처표시, 상업적 이용 및 변경 가능)이며, 제공 페이지는 표준 운행시간이 열차 사정에 따라 달라질 수 있다고 안내합니다.

서울교통공사 제공 자료를 HA for Korea에서 경로 검색용으로 변환했습니다.
원본 사이트의 프로그램 코드를 실행하거나 통합 코드로 복사하지 않습니다.
변환된 사실 데이터의 출처와 입력 파일 SHA-256은 JSON의 `source`에 기록했습니다.
이 출처 표기는 프로젝트 코드의 라이선스와 별개입니다.

## 소요시간과 방향

공식 CSV의 소요시간은 바로 앞 행의 역에서 해당 행의 역까지 걸리는 시간으로 읽습니다.
현재 노선도에 실제 연결이 있는 역 쌍에만 적용합니다. 역 이름이 같아도 노선이 다르면 서로 다른 승강장입니다.

공식 시간이 없는 역간 연결은 **3분**, 환승은 **5분**으로 추정하며 `estimated: true`로 구별합니다.
급행·운행 시간표·대기 시간·막차·실시간 운행 중단은 정적 경로 계산에 포함하지 않습니다.
따라서 제시한 경로와 시간은 참고용이며 실제 출발 시각을 보장하지 않습니다.

1~9호선의 기본 상행·하행(2호선 본선은 내선·외선)을 기록했습니다.
1호선은 운영 구간별 역 코드가 달라 코드의 대소만으로 방향을 판단하지 않습니다.
6호선 응암 순환 구간은 응암 → 역촌 → 불광 → 독바위 → 연신내 → 구산 → 응암의 단방향입니다.
순환 구간의 `상행` 표시는 응암 방면의 순환 진입 기준이며, 실제 API가 내보내는 열차 방향은 개별 운행에 따라 확인해야 합니다.
기타 노선의 API 방향을 검증하지 않은 연결은 빈 문자열을 사용하며, 임의 방향으로 실시간 열차를 선택하지 않습니다.

GTX-A의 북부·남부 구간 사이에는 운행 연결을 만들지 않습니다.
같은 이름의 신촌역처럼 서로 다른 역은 이름만으로 환승 처리하지 않습니다.
서울교통공사 자료의 공통 환승 식별자로 연결합니다. 한강버스와 지도 장식용 선은 제외합니다.

## 다시 생성

`getLineData.do` 응답을 실행하지 않고 JSON 객체로 파싱한 파일과 위 CSV를 준비한 후 실행합니다.
역·노선 변경 시 원본 확인일과 출처를 함께 갱신하고 회귀 검사를 실행합니다.

```console
python tools/build-subway-network.py --lines metro-lines.json --times metro-times.csv --updated 2026-10-05
python -m pytest tests/test_subway_network.py
```

JSON에는 `stations`, `lines`, `edges`, `source`, `updated`가 있습니다.
승강장 ID는 `노선ID:원본역코드`, `group`은 원본 환승 식별자입니다.
선별한 API 지원 노선은 서울 실시간 도착정보 API의 노선 ID를 사용합니다.

## 노선도 표시

카드는 공식 사이버스테이션의 좌표·연결 자료를 자체 SVG로 표시합니다.
별도의 비공식 SVG를 공식 자료로 취급하지 않습니다. 확대·이동 시 겹치는 역명은
우선순위에 따라 숨기며, 선택한 경로의 역명을 먼저 표시합니다.
서울시 [노선도 디자인 자료](https://news.seoul.go.kr/culture/archives/522224)의
국문 다운로드는 2026-10-05 확인 시 JPG였으며, 공개 SVG 파일은 확인하지 못했습니다.
